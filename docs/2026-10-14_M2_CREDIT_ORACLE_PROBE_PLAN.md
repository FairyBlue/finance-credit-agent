# M2 功劳分配 CPU 机制实验方案

2026-10-14，SGT。用户已授权执行本次CPU机制试验；此方案在数值模拟运行前保存并绑定SHA。依据[上一轮存档分析](2026-10-14_M2_ACTION_POOLING_MECHANISM_REPORT.md)，本次检验动作族池化是否更准确估计具体订单的功劳，不以残差能量变小作为有效性标准。

## 账务和真实答案

使用既有PortfolioLedger、单边10bps手续费和5bps滑点，不更改训练、奖励或账务源码。合成股票A/B的建仓及下一开盘价均为100，下一收盘固定基础涨跌为A＋4%、B−3%。从100万现金出发，在两个前序next-open分别建仓A/B至20%，形成可复现共同状态；实际费用后的现金、股份和净资产由账务引擎给出，不假定其恰好为60/20/20。

具体动作冻结为buy A到40%、buy B到40%、sell A到0、sell B到0、hold。每个动作从同一个状态复制分支，下一开盘成交。q为下一收盘净资产相对该状态hold分支的增益，除以该状态决策前净资产、乘100，单位为百分点。各组oracle为q减去本组q均值，始终以具体动作效果为答案，不以动作族均值为答案。

合成终分为`Y_i = hold_payoff(s_i) + q_i + 100*post_exposure_i*z_group + epsilon_i`。Exposure取股份乘共同开盘价格、除以各自决策前净资产；市场z对A/B同时施加。另以共同常数C检验不变性。q、Y、C和epsilon均用百分点，z用收益率小数。

主指标对期望动作效果q中心化；次指标对实现效果`q_i + 100*(post_exposure_i−pre_exposure_i)*z_group`中心化。市场交互可能改变真实动作效果，不一概称为噪声。Epsilon是当前动作无关的后续路径扰动，只用于合成机制压力测试；它不代表一日固定hold回放自身有随机收益。

## 固定场景和比较

| 场景 | 四个基础成员 | 回答的问题 |
|---|---|---|
| 同质正控制 | buy A、buy A、hold、hold | 相同具体动作的平均是否降低独立扰动误差 |
| 同族异质 | buy A、buy B、hold、hold | 股票效果相反时，粗族是否引入偏差并抹掉排序 |
| 全singleton | buy A、buy B、sell A、sell B | 精确分组没有同伴时的覆盖边界 |
| 单族gate盲点 | buy A、buy A、buy B、buy B | 具体订单不同但全是buy时，原gate是否漏掉真实差异 |
| 状态异质压力测试 | buy A、buy B、hold、hold | 从不同组合出发时，原终分是否混入继承持仓收益 |

状态压力测试的四个前序A/B目标依次为10/10%、20/20%、30/10%、10/30%，每个q及exposure均重新通过账务构造，不能只给Y任意增加偏移。

同一组Y比较四种残差：plain、当前family pool、exact order pool但保留原family gate、exact order pool并使用具体订单分歧gate。后两项是新诊断候选；改变pooling和改变gate分别呈现。状态压力测试另报告减去真实hold基线和继承市场暴露后的oracle参照，明确它使用oracle信息，不是可部署候选，也不能把其改善归给池化。

主分析n=4；n=8/16仅将相同成员构成重复并独立重采epsilon，作为便宜的样本量敏感度。n=4结果与生产compute_sibling_credit公式交叉核对，n=8/16是诊断扩展，不是生产配置。

市场z标准差固定为0、0.03、0.10；epsilon标准差固定为0、0.25、1个百分点。两组模拟seed固定1729、1730，每个场景、n和噪声组合各4096个独立group；同group内各方法共享所有随机数。共1,105,920个合成group、10,321,920个成员，不是LLM轨迹或训练更新。共同C取0、2、8百分点，仅在原Y上配对平移检查，不增加收益采样。

## 指标和判读

所有group、所有成员纳入均方误差，包含gate关闭和singleton；分母不随方法选结果。排序只排除oracle确实相等的pair，预测tie计0.5，同时报告严格正确、错误与tie比例。另报告非零oracle的正负方向、预测为零比例、gate覆盖、peer覆盖、组内能量变化。误差与排序分别对期望和实现效果报告。Monte Carlo标准误只表示合成随机模拟误差，不是金融收益置信区间。

工程核验检查公共费用账务、source SHA、n=4真实公式、共同常数不变性、独立噪声同质正控制的解析MSE，以及零噪声具体动作排序。发现粗族偏差或gate盲点是科学结果，不能写成程序失败。

若仅在同质高噪声场景获益，结论限定为该条件下平均降方差；若同族异质场景零噪声已有偏差，优先重审分组/估计目标。细分候选同时改善预设误差和排序时，最多建议进一步Train内开发验证。不得根据本次结果选噪声档、扩大GPU训练或改动既有正式终点。

可以追加一个预先指定的现实桥接案例：既有Train开发窗口0378、seed42、step4 greedy的第5个决策，重放共同历史至相同组合，比较两个历史sell订单与hold，并使用共同hold后续规则到窗口终点。它是条件回放例子，不是新策略评测或独立样本。Formal Valid和Final OOS不读取，现有人工审核和正式训练门禁保持有效。
