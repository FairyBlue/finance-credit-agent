# 金融Agent学习与功劳分配Demo简报

日期：2026-10-28。定位：研究与工程demo；当前交易扩训收尾，原第三步RL对照不继续启动。

本项目已实现一套可运行的金融Agent实验系统：在按当时信息可见性提供的行情上，完成工具调用、成本记账、SFT/RL训练、同状态分支估值与完整轨迹复评。主要成果是把“交易行为是否正确、credit是否可比、模型是否真正更新、收益是否改善”连成一条可追查的实验链路。

## Demo的创新点与技术贡献

这里的创新点指本demo的设计特色和工程贡献，不将已有RL组件包装为算法首创。

1. **将金融账务与Agent训练统一起来。** Agent与基准共用次日开盘成交、手续费、滑点和现金/股份账本；同时报告净收益、基准超额、金融Y、拒单、费用与完整率，避免只优化一个漂亮分数。
2. **让局部credit有真实可比较的状态。** 从同一已发生前缀分支，保留同一持仓、现金、历史动作和模型上下文，比较不同经济订单及后续结果；按具体股票、目标权重等经济含义区分动作，检验粗动作族分组、同订单池化和固定收缩的作用。
3. **完成实际训练与恢复链路。** 在4B级Qwen3模型上接通SFT、RLOO/PPO更新、跨批持久FP32主权重/Adam和BF16推理导出；随后复用LoRA完成新组合接口的共同初始化。不是只做离线打分或提示词展示。
4. **形成可诊断的组合管理原型。** 共同扣费建立等权底仓，每5日选择组合动作，账务逐日推进；连续hold可逐点复制被动持有。支持固定被动后续的确定性教师与当前策略续写估值，并明确区分两者。

前缀Monte Carlo估值、同状态相对优势、自适应步级权重已有相关工作：[VinePPO](https://arxiv.org/abs/2410.01679)、[GiGPO](https://arxiv.org/abs/2505.10978)、[AdaStep](https://arxiv.org/abs/2610.03223)。本demo尚未建立超越这些方法的性能证据。

## 主要结果

**原单票交易接口：完整Valid开发比较。** 五组各120条轨迹全部完成，覆盖60个重叠窗口；表中为扣费后的窗口平均净收益。

| 方案 | Valid净收益 |
|---|---:|
| 共同SFT | −0.08305% |
| 原16步RLOO | +0.15323% |
| 扩大至80步RLOO | −0.04260% |
| 共同菜单控制 | +0.01370% |
| 学习订单评分器 | −0.31100% |
| 等权持有 | +0.77548% |

原RLOO对SFT有+0.23628个百分点，但仍低于等权持有；扩大训练、动作池化及评分器没有建立稳定收益优势。证据：[主实验报告](../runs/m2-broad-rloo-order-main-20261028-v1/FINAL_REPORT.md)。

**新组合接口：确定性教师与共同初始化。** 354个学习窗生成3540个真实状态、14160条CPU确定性分支；一轮LoRA完成222次更新。训练前后两模型共128条预定评估轨迹全部完成。

| 方案 | 学习区32窗 | 开发区32窗 |
|---|---:|---:|
| 原共同SFT | 1.49954% | 2.46718% |
| 新教师SFT | 1.61741% | 2.50110% |
| 被动等权持有 | 1.65344% | 2.59195% |

开发区仅+0.03392个百分点，去掉最大正贡献窗后为−0.00762个百分点；117/128次决策为反转，平均费用2044.78→2593.92。初始化已跑通，仍不能称为稳定的主动管理优势。证据：[初始化报告](../runs/m2-portfolio-teacher-sft-20261028-v1/REPORT.md)、[真实轨迹演示](../runs/m2-portfolio-management-step1-20261028-v1/REPORT.md)。

## 结论与展示口径

可以展示的成果是：**具备真实成本、模型更新、同状态反事实评估与完整对照的金融Agent研究系统，以及可运行的组合管理demo。** 实验明确区分了工程接通、估计误差改善与交易收益改善，负结果和失败轨迹均保留。

目前没有证明M2优于强基线，没有证明获得稳定市场超额收益，也不能由这些结果否定所有credit方法。两套接口/日期的结果不拼接；滚动窗口不是独立市场样本。新增教师监督的开发区按日期隔离，但原底座已有旧Train暴露；Final OOS仍未使用。下一轮转向可验证的金融任务与信息决策，先建立有价值的动作差异，再比较credit。
