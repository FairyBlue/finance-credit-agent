## 持久证据与门禁

聚合结果位于 [`configs/t2_v2_result.json`](../configs/t2_v2_result.json)，原始字节 SHA-256 为
`aff81d0af5fb458768abd741264ce312a7c0767884069824a7e309286ea27436`。artifact 不包含强/弱正控制
特征或翻转数组，只保留复核三条件所需的聚合统计。

正式 launcher 不信任 artifact 中的 `passed` 布尔值本身，而是重新验证：

- artifact 原始字节哈希与预注册 protocol hash；
- history manifest、文件数、Train/Valid 样本和 session 数；
- 每个分支的 bootstrap 参数与样本身份；
- 强正控检出、弱正控检出、真实管道未显著检出的联合语义；
- `stockbench_oos_accessed=false`，且没有额外正控制载荷字段。

任一缺失、篡改或配置漂移都会 fail closed；旧 `scripts/run_t2_probe.py` 继续永久禁用，不存在
StockBench OOS fallback。

## 边界

本结果解除的是 T2 v2 这一项正式训练阻塞，不自动批准或启动正式 A1/A2/A3。正式实验仍需满足
干净 commit、正式 reviewed manifests、完整 preflight 等条件；A3 科学主结论还需要实现并预注册
M2 或 M3。Final OOS 继续关闭，直至最终一次科学评测。
