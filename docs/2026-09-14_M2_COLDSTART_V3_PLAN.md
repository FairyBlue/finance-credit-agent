# 共同冷启动 v3：补充模型实际产生的 Train 状态

制定时间：2026-09-14 00:20 SGT（UTC+8）。本计划在新采集和补训前确定。

共同冷启动 v2 已完成，但两套非法率仍为 12.93% 和 11.43%，未通过 5% 门槛。
旧回归短回合非法率已降至 4.76%，完整回合仍有 17.18%；训练后多数错误是在当前
仓位超过 20% 时仍 buy 到 20%。自主教师的全部买入标签是 20%，全部卖出标签
是清仓；带明确意图的 API 保持示范没有充分迁移为自主 hold。成本上升、长回合
收益下降均保留在 [v2 报告](2026-09-13_M2_COLDSTART_V2_REPORT.md)。

本轮只改变自主训练状态的来源：从手工固定的单步状态，补到模型自己在完整回合中
产生的持仓和错误反馈状态。延用现有离线教师、模型接口和验收要求。这是一次有界
的示范聚合补训；不宣称消除了教师的 20%/清仓先验，也不宣称是 M2 奖励改进。

## 原 Train 采集

- 起点：`runs/m2-coldstart-v2-20260913/merged_model`，逐文件大小与 SHA-256 核验。
- 仅取原示范来源 `coldstart_data.TRAIN_IDS` 的固定索引 `[0,3,5,8,11,14,16,19]`，
  共八个 21-session Train 窗口，均从真实全现金开始，没有教师动作前缀。
- 各窗口一条 greedy、四条 sampled，共 40 条完整回合请求计划；seed42，采样参数
  和请求种子派生沿用 `coldstart_eval`。每条 128 请求上限，prompt8192、response4096。
- 延用 `history_features_v1`、`single_tool_portfolio_v1`、non-thinking、原 vLLM。
  逐请求保留 prompt、token IDs、响应、环境回执、错误、成交与财务轨迹。
- 采集结果是 Train 数据来源，不是新验收结果。所有非法请求按原环境拒绝，不自动
  改成另一方向、成交或 hold。预算耗尽的轨迹保留 INCOMPLETE；其中完整可复现的
  早期状态仍可标注，绝不据此把整条轨迹改为完整。
- 源日期及教师未来日期不晚于 2023-05-22，且与两套保留的 Train 验收日期无交集。
  不复制 v2 验收 prompt 或对应交易路径作为训练数据。

## 状态重放与离线教师

为每个候选训练状态，从原始完整窗口重放模型此前的实际请求，包括拒单及不推进
日期的工具调用。重新渲染的 prompt 和 token IDs 必须与采集记录完全一致。
每个状态保留到达它的轨迹、request index、当前持仓、此前错误和源文件身份。

只标注当前日期之后还有三个 session 的状态。离线候选仍为 hold、GS/MSFT/HD
合法 buy 到 10%/20%、合法 sell 到 0%/10%；候选按可见当前权重过滤。候选执行后
hold 到当前 index+3，以实际成本后的账户净值选择标签，经济相同优先 hold。
不得直接使用旧评分函数的“推进到整个 episode 结束”，也不得截短原环境以致改变
模型看见的剩余日期或 prompt。未来价格只进入离线标签，不进入模型输入。

原模型调用和教师 completion 分开记录。教师标签必须在对应真实状态合法执行，
记录候选成交、跳过订单和成本；不把原非法请求重写为教师调用。回放核对失败立即
停止构建，不丢弃难例以通过验证。

新增最多 640 个不同 prompt：

1. 先选本次真实非法请求时的状态，以及它的下一次实际请求状态；同 prompt 去重。
   只有可完整复现、具备三日教师范围的状态可用，所有排除原因计数保留。
2. 若上述优先集合超过 640，停止数据构建并保留原始证据；不悄悄删除错误状态。
3. 剩余额度按固定偶数 request index，从各轨迹轮流取合法普通状态，再按 prompt
   去重。选择发生在教师评分前，不按买卖标签、收益或股票筛选。
4. 与 v2 的全部 740 条示范聚合，各保留一次，最多 1380 条。不得为平衡买卖比例
   覆盖自主标签。原 API 示例继续明确区分；新增自主示范不附“请买/请卖”的意图。

实际状态覆盖、已有股票数、当前权重上下边界、持仓保持、标签分布及教师目标集中
程度全部报告。若仍以 20%/清仓为主，明确保留这个局限。

## 固定补训与验收

从 v2 完整模型开始，固定两轮 SFT：lr5e-5、LoRA rank16/alpha32、原七个线性投影、
dropout0、micro2、accum8、seed42、completion+EOS loss、BF16、8192长度硬限制，
不截断。最多 174 次更新；以实际数据数和最后不足整批的更新规则报告精确计数。
只导出最终 checkpoint，不根据验收收益挑选中间模型。

v2 的 `after_regression` 和 `after_fresh` 作为本轮训练前结果复用，逐文件复制并
绑定源哈希，明确不是重新生成；模型、上下文、协议和依赖源文件必须一致。
补训后重新生成相同旧回归 100 条和日期隔离 Train 85 条，保留 seed/预算。第二套
已被 v2 查看，因此本轮称“重复使用的日期隔离 Train 验收”，不再称新鲜或独立 OOS。
原 21-session 和新增区间的 15-session 长回合分开报告。

沿用 v2 已固定的共同初始化要求：两套各自全部完整、非法请求率各不超过 5%；
40 条错误前缀轨迹全部完整且模型非法率不超过 5%；两套各至少一半 sampled
contexts 的四兄弟完整且净收益范围大于 1e-8；至少一半完整 full sampled 轨迹
在两个或以上日期真实成交。预置交易与拒单不计入模型行为。

同时报告 hold、买卖、股票覆盖、集中度、成本、净收益和错误重复情况。达到门槛
只表示可进入短 RL 的共同初始化，不表示优于 benchmark，也不表示 M2 有增益。
FAIL 时保留本轮模型和原始结果，结束这次固定补训并分析具体残留问题；不在控制器
里无限增加 epoch、重抽或放宽阈值。

共同起点通过后，保留未 RL 的 SFT 基线，使用相同 actor/reference/critic backbone
及共同 critic seed 做固定两轮 M1/M2 对照。该条件分支单独记录实际启动与结果，
不把已准备的代码或服务模板写成训练已经发生。
