## 唯一训练改动

保留共同 SFT v3、actor LR `2e-7`、critic LR `1e-6`、原 GSPO、non-thinking、
M2 `η=0.25`、scorer 与 generation 参数。
原始金融评分记为 `Y`，完整轨迹真实请求数为 `N`，新增共同训练奖励：

```text
r′_t = r_t − 0.05 × 1[environment rejected request t]
r_t  = Y / N                 # 末步保留原有浮点守恒尾差
sum(r′) = Y − 0.05 × N_invalid
```

- `invalid` 只用现有环境拒单标记；不按事后收益或教师偏好判定动作对错。
- M1、M2 使用完全相同的 `r′`。两臂 GAE/critic returns 都来自 `r′`，不只在 actor 端临时扣分。
- M2 的 sibling residual 仍从**原始金融 Y**计算；额外信用公式、门控及 `η` 不变。
- 验收继续报告原始含成本净收益、原始 Y、非法率、完整率和交易行为；罚后训练总分另列，避免混用。
- 这是 `Y − 0.05 × N_invalid` 的新共同训练目标，必须使用新身份并披露；不是修复现有公式的实现错误。
- 不同时改变窗口归一化、critic 安排、交易接口或推理时动作规则，不屏蔽/自动改写非法请求。

`0.05` 是固定的首个试探值，小于当前训练即时奖励绝对值中位数（约 0.13–0.14）。
它未通过验收收益挑选，也不是最优系数；不把“所有非法 A 都变负”设成机械目标。
γ=λ=1 时未来奖励仍进入非法步骤的 return，局部惩罚不保证最终 advantage 为负。
