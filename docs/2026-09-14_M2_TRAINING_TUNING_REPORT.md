η=0.25 第二轮为 **2.281889%**，比共同 SFT 高 **0.633194 个百分点**，四窗均改善；

因此本批支持“早期有改善线索，继续更新后未能保持”，不支持“降低 η 已解决训练问题”，
也不能把事后表现最好的第二轮当作预先选定的最终模型。本轮只保存了第八轮 actor，早期点保存的是轨迹与指标。

## 行为与训练读数

最终四窗实际成交股票仍只有 **GS、HD、MSFT**，没有扩大覆盖。各组峰值单股权重约 20.6%；
末期现金比例提高、部分 hold 增加，与交易行为发生变化一致，但不能仅凭这些汇总认定收益下降的因果。
η=1 成本降幅较大，却没有抵消净收益下降；“少交易”本身不能作为成功标准。

与 sampled 训练行为不能混为一项。

主比较的 critic post half-MSE 范围约 **0.260–6.913**，未再出现诊断中首轮约 60.663 的大过冲；
但三个臂的第 1、5 轮仍出现同批 loss 小幅增加，并非每次更新都改善。
每轮训练窗口和目标分布不同，不能把跨轮 loss 的变化直接解释成收敛或发散。
各臂 actor KL 相对早期总体增大，这是后续检查更新幅度的线索，尚不能认定为退化原因。

M2 两种 η 均有实际非零额外信号。日志中的 `std(ηS)` 已包含 η；全部真实请求上，
`std(ηS)/std(U)` 在 η=1 时约 **0.107–0.658**，η=0.25 时约 **0.010–0.179**。
较弱配置确实提供了更弱的额外信号，但第八轮没有因此更好。

**原学习率首轮造成明显过冲，次轮又纠正了大部分高估；降低十倍后，两轮更新均改善了各自同批拟合。**
低学习率两轮 post loss 都更低，两轮平均绝对 post bias 从 6.8408 降至 0.4942，
满足事前自动选择条件。选择只依据 critic 拟合，不读取投资收益。
第二轮仍有约 -0.978 的平均偏差，不能把这一结果称为 critic 已收敛或已保证 RL 收益改善。
