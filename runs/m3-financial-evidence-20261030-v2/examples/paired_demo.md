# 同一财报、两个阈值：SFT完成不同的条件委托

本例取自本轮 **v2固定Dev** 的教师SFT实际轨迹。两题使用同一财报、账户、报价和证据，只有模拟委托的阈值不同；两题均已完整成功。本文只整理已有日志，不采样、不再重放或测试、不读取Test，也不据一个配对估计平均因果效应。

## 同一财报指标

证据来自FinQA原始报告片段 **`C/2009/page_63.pdf-3`**。原问题为：“in 2010 what was the percent of the contractual obligations by year long-term debt obligations to the total”。这里**报告年度是2009，问题指定期间是2010**。

SFT在两条轨迹中都实际调用：

```text
calculate: 47162.0 / 83659.0
returned:  0.5637409005606091
```

因此提交指标均为 **0.5637409005606091（约56.374090%）**，`period="2010"`、`unit="ratio"`，引用相同的当前委托与财报证据。

模拟客户条款规定：该指标**大于阈值**时，将组合资产 **V** 的权重上限收紧到10%；否则上限为40%。财报参考公司C和组合资产V的关联是本例明确指定的模拟合同规则，不把这份财报当作V公司的财报。

## 实际提交与执行

两题初始组合均为750,000美元净资产；V持仓779.9500534914475股，权重30%，现金112,500美元。固定已知报价下采用相同手续费与滑点规则。

| 项目 | 阈值版本A | 阈值版本B |
|---|---:|---:|
| 内部日志编号 | `financial-0419-v0` | `financial-0419-v1` |
| 委托阈值（ratio） | 0.5355538555325786 | 0.5919279455886396 |
| 阈值换算百分比 | 约53.555386% | 约59.192795% |
| 实际提交的指标 | 0.5637409005606091 | 0.5637409005606091 |
| 实际提交的`triggered` | `true` | `false` |
| 实际传给solver的V上限 | 10% | 40% |
| 最终V持仓 | 259.9053704635959股 | 779.9500534914475股 |
| 最终V权重 | 10% | 30% |
| 实际成交笔数 | 1 | 0 |
| 实际原始成交名义金额 | 150,022.495873美元 | 0美元 |
| 实际手续费＋滑点 | 224.958733美元 | 0美元 |
| 最终现金 | 262,297.537141美元 | 112,500美元 |
| 最终净资产 | 749,775.041267美元 | 750,000美元 |
| 完整任务核验 | 成功 | 成功 |

版本A中，56.374090%大于53.555386%，SFT提交触发为真、将V上限设为10%，随后实际卖出约520.044683股V并计入成本。版本B中，同一指标低于59.192795%，SFT提交触发为假、保留40%上限；原有30%持仓已经合法，实际执行没有交易。**上限40%不要求买到40%。**
