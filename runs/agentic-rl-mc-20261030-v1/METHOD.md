# 本轮估计与最近邻差异

2026-10-30；此页是最小原型说明，不是新颖性或训练效果结论。

本轮估计动作前当前策略状态价值Vπ(h)。恢复真实环境、缓存、消息与原剩余工具预算，从动作前重新采样两条独立完整续写；辅助回报均值替换该step的baseline，父回报不混入均值。环境只有终局reward，包含工具调用成本，因此父与辅助都使用原terminal_reward，共有前缀成本在同状态比较中相同。

所有父步骤保留训练，未选择的步骤使用共同RLOO baseline。辅助轨迹只估计V，不作为actor样本；不把遮蔽信息效应或搜索策略的Q当当前策略动作advantage。各臂共用LoRA PPO损失、一次全batch优势归一化和持久FP32/Adam。动作无关baseline在独立等条件下的标准性质，不是整个PPO/长度归一化/白化更新严格无偏的保证。

选点固定：均匀概率p=.12。候选使用p=min(.6,.12*(.25+.75*score))；score为阶段权重×公开搜索歧义倍率/预计剩余调用比例。阶段权重为信息获取.2、已读财报待算2、算后1、solve后.4、错误反馈后修复2.5；歧义只看历史搜索候选数，成本只看剩余调用，具体见financial_mc_selection.py。保留25%均匀混合，每父迹最多一个anchor，每个pair预留2×剩余调用×16384token。该启发式不是已提出的新算法。选择、主采样和辅助续写使用独立命名的RNG流。

第一步复用同SFT旧128父轨迹，选择仅重放其动作前公开历史，不读取该父动作或终局；不声称选择是在历史生成时已记录。第二步的collector在llm.generate之前实时落盘选择。首批8anchors/16续写，282676新增输入+输出token；旧父数据3308883token记为复用曝光，不重复计新生成。

| 最近邻 | 与本轮实际实现的关系 |
|---|---|
| VinePPO | MC状态价值思路相近；本轮是工具环境的有限预算适配，不是完整复现或新估计器 |
| ASCT | 比较同前缀合法动作，辅助树产生动作价值并服务PPO；本轮采样原生当前π，不枚举有限动作菜单，也不构造搜索Q表 |
| APPO | 研究分支位置及分支后credit；本轮只在完整交互前缀选择V估计位置，比较均匀与一档公开阶段/成本优先规则 |
| AdaStep | 局部advantage收缩；本轮不扫/学习收缩系数，不添加遮蔽残差 |

具体比较只改变额外续写的分配；估计误差、baseline非零和接线成功都不代替实际策略学习效果。三臂结果及其预算出口按docs/2026-10-30_AGENTIC_RL_THREE_STEP_PLAN.md执行。
